# 简历要点

## 中文

**CommerceOps｜电商数据运营与交易管理系统｜独立开发**

- 设计并实现覆盖用户、商家、商品、订单、物流、评价和客服的电商业务工作台，基于三种角色组织差异化操作路径。
- 使用 Streamlit、MySQL、Pandas 与 Plotly 完成业务 CRUD、交易趋势、商品反馈和运营指标可视化，并编写外键、触发器与存储过程维护数据一致性。
- 搭建 Docker Compose 本地环境、数据库配置模板、可恢复 SQL 备份和自动语法检查流程，降低项目复现成本。

## English

- Built a role-based ecommerce operations platform spanning users, merchants, products, orders, logistics, reviews, and customer support.
- Implemented transactional CRUD and Plotly analytics with Streamlit, Pandas, and MySQL, including foreign keys, triggers, and stored procedures.
- Added a reproducible Docker Compose environment, configuration template, recoverable SQL backup, and automated syntax checks.

不使用未经测量的业务增长、用户量或效率数据。
